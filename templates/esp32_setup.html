Hardware Wiring Specification
Standard TTL to RS485
Module / Component Sensor / Transceiver Pin ESP32 / System Connection Electrical Rationale
7-in-1 Sensor Power VCC (Brown / Red) External DC Power (9V - 24V) Soil probes demand 9-24V DC. Do not power from ESP32 3.3V pin!
7-in-1 Sensor Ground GND (Black) Common External GND + ESP32 GND Ground reference must be shared across all modules to avoid floating voltages.
Modbus Differential A RS485 A (Yellow / Green) MAX485 Pin 'A' Non-inverting RS485 differential data line.
Modbus Differential B RS485 B (Blue / White) MAX485 Pin 'B' Inverting RS485 differential data line.
MAX485 Power VCC & GND ESP32 5V (or 3.3V) & GND Powers the transceiver IC. Check module operating voltage.
MAX485 Receiver Out (RO) RO ESP32 GPIO 16 (UART2 RX) Receives serial bytes from sensor into ESP32 hardware UART2.
MAX485 Driver In (DI) DI ESP32 GPIO 17 (UART2 TX) Transmits Modbus query commands from ESP32 to sensor.
MAX485 Flow Control DE & RE (Tied Together) ESP32 GPIO 4 HIGH = Transmit Query Mode; LOW = Receive Sensor Response Mode.
Crucial Network Requirement: Do NOT Use "localhost" in ESP32

The ESP32 is an independent device on your local Wi-Fi router. If you configure http://localhost:5000 in your ESP32 code, the ESP32 will attempt to connect to itself and fail.

Step 1: Open PowerShell or Command Prompt on Windows.
Step 2: Run ipconfig and note your IPv4 Address (e.g. 192.168.1.105).
Step 3: Configure the Arduino sketch with your PC IP address:
const char* SERVER_URL = "http://192.168.1.105:5000/api/soil-data";
Modbus Register Map Customization

Different 7-in-1 sensor manufacturers use different starting register maps. The included firmware provides a centralized configuration section at the top of smart_soil_esp32.ino: 

// Common Type A: Sequential 7 registers starting at 0x0000
const uint16_t MODBUS_START_REGISTER = 0x0000;
const uint16_t MODBUS_REGISTER_COUNT = 0x0007;

// Common Type B: Starting at 0x001E
// const uint16_t MODBUS_START_REGISTER = 0x001E;
// const uint16_t MODBUS_REGISTER_COUNT = 0x0007;

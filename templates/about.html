AgriAdvisor

IoT-Based Soil Monitoring, Telemetry Analytics & Crop Optimization Platform

An end-to-end cyber-physical agricultural intelligence system integrating a 7-in-1 Modbus RTU RS485 soil probe, an ESP32 micro-controller node, Wi-Fi telemetry transmission, a high-performance Flask REST API backend, an SQLite relational database, and an algorithmic crop suitability and soil health optimization engine.

Backend & API Stack
  • Python 3.12: Core application environment
  • Flask 3.x: RESTful microservices and routing
  • SQLAlchemy ORM: Database abstraction & query security
  • SQLite: Local embedded zero-config relational store
  • ReportLab: Automated vector PDF report generation
Frontend Stack
  • Semantic HTML5: Accessible document architecture
  • Modern CSS3: Responsive Grid, Flexbox, custom design tokens
  • Chart.js 4.4: High-performance canvas interactive charts
  • Vanilla JavaScript (ES6+): Async/Await, reactive polling
  • FontAwesome 6: Comprehensive icons
Hardware & IoT Stack
  • ESP32 DevKit: Dual-core 240MHz Wi-Fi microcontroller
  • MAX485 Module: Full RS485 transceiver with flow control
  • 7-in-1 Sensor: Industrial probe (NPK + pH + EC + Moisture + Temp)
  • Modbus RTU: Robust 16-bit CRC differential industrial bus
